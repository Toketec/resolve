# 生态资源使用说明 — RESOLVE

> 本文档说明 RESOLVE 如何集成 HTX 生态资源，按照 HTX Genesis 黑客松提交规范的要求编写。

---

## 概览

RESOLVE 在架构中集成了 **3 项 HTX 生态资源**：HTX 公开 API（行情数据）、B.AI 8004 协议（Agent 身份）、B.AI x402 协议（自主微支付）。此外，项目还使用 TRON Shasta 测试网进行链上结算，并在 UI 中展示 $HTX 代币经济模型。

---

## 1. HTX 公开 API — BTC/USDD 实时价格数据

| 字段 | 说明 |
|------|------|
| **资源** | HTX REST API（公开市场数据） |
| **接口** | `GET https://api.htx.com/market/detail/merged?symbol=btcusdd` |
| **类型** | 只读 HTTP（无需鉴权） |
| **使用位置** | BULL-1（交易所 Agent）— 将价格、订单簿深度、24小时成交量作为看多/看空分析的证据 |
| **重要性** | 提供**实时、可验证的市场数据**，AI Agent 以此为主要证据来源，而非模拟价格 |
| **评分维度** | 生态契合度——直接调用 HTX API |

### 使用的数据

| 数据点 | Agent 用途 |
|--------|-----------|
| `close`（最新价） | 与目标价格对比 → 方向性信号 |
| `high` / `low`（24h 范围） | 波动率评估 → 置信度调整 |
| `amount`（24h 成交量） | 市场参与度 → 信号强度 |

## 2. B.AI 8004 协议 — 链上 Agent 身份

| 字段 | 说明 |
|------|------|
| **资源** | B.AI 8004 Agent 身份协议 |
| **交互方式** | 在 TRON 上注册每个 AI Agent 为验证过的 8004 兼容身份 |
| **类型** | 链上交易（TRON 测试网） |
| **使用位置** | Agent 池初始化——6 个 Agent（BULL-1/2、BEAR-1/2、NEUT-1/2）各获得一个唯一的 8004 身份 |
| **重要性** | 将 Agent 从"匿名 LLM 调用"升级为**链上可验证实体**——这是 AI×Web3 融合的核心要素 |
| **评分维度** | AI/Web3 应用程度——真实的链上 Agent 身份，而非数据库条目 |

### 实现方式

```
┌─────────────────────────────────────────────────┐
│  Agent 池初始化                                  │
│                                                  │
│  bull-1 → 注册 8004 身份 → 0x...a1f2            │
│  bull-2 → 注册 8004 身份 → 0x...b3c4            │
│  bear-1 → 注册 8004 身份 → 0x...d5e6            │
│  bear-2 → 注册 8004 身份 → 0x...f7g8            │
│  neut-1 → 注册 8004 身份 → 0x...h9i0            │
│  neut-2 → 注册 8004 身份 → 0x...j1k2            │
└─────────────────────────────────────────────────┘
```

每个 Agent 的 8004 ID 在其 UI 卡片上显示，演示过程中可见。

## 3. B.AI x402 协议 — Agent 自主结算费支付

| 字段 | 说明 |
|------|------|
| **资源** | B.AI x402 微支付协议 |
| **交互方式** | Agent 钱包在触发结算时自主支付微手续费 |
| **类型** | 链上交易（TRON 测试网） |
| **使用位置** | 结算流水线——共识达成后、链上支付前，Agent 钱包发起 x402 微支付 |
| **重要性** | 展示 **Agent 经济自主性**：Agent 自主支付算力/结算成本，而非由中心化实体补贴 |
| **评分维度** | AI/Web3 应用 + 技术创新——自主 Agent 经济 |

### 流程

```
共识达成
     ↓
Agent 钱包检查费用余额
     ↓
向结算合约发送 x402 微支付
     ↓
结算合约验证支付 → 释放 payout
```

## 4. TRON Shasta 测试网 — 链上结算

| 字段 | 说明 |
|------|------|
| **资源** | TRON Shasta 测试网（通过 TronGrid 公共节点） |
| **交互方式** | 部署结算合约、处理买入订单、执行结算支付 |
| **类型** | 智能合约部署与执行 |
| **使用位置** | 整个结算层——钱包连接、买入份额、市场结算 |
| **重要性** | 所有价值转移发生在真实的 TRON 测试网上，而非模拟——评委可在 ShastaScan 上验证交易 |
| **评分维度** | 产品完成度 + Web3 应用 |

## 5. $HTX 代币经济（UI 展示）

| 字段 | 说明 |
|------|------|
| **资源** | $HTX 代币经济模型（展示层，无真实兑换） |
| **交互方式** | 交易面板显示 $HTX 费率折扣；仪表板显示累计 $HTX 回购数量 |
| **类型** | UI 展示（演示中无链上交互） |
| **使用位置** | 交易面板、KPI 仪表板卡片 |
| **重要性** | 展示对代币经济设计的理解——$HTX 作为费用效用代币，与 HTX DAO 生态对齐 |
| **评分维度** | 商业与生态潜力——代币经济模型设计 |

### 经济模型

| 机制 | 说明 | UI 可见 |
|------|------|---------|
| **$HTX 费率折扣** | 质押 $HTX 后交易费率从 0.5% 降至 0.3% | 交易面板显示两种费率 |
| **$HTX 回购池** | 每笔交易手续费的 0.1% 进入回购池 → 提升底价需求 | KPI 仪表板卡片 |
| **$HTX 收益** | Agent 卡片显示通过裁决已赚取的 $HTX 数量 | Agent 详情面板 |

## 生态集成汇总

| 资源 | 集成深度 | 评委可见性 | 对应评分维度 |
|------|:--------:|:----------:|:-----------:|
| HTX 公开 API | Agent 证据中的实时价格数据 | 证据面板显示实时 HTX 数据 | 生态契合度 |
| B.AI 8004 协议 | 链上 Agent 身份注册 | Agent 卡片显示 8004 ID | AI/Web3 融合 |
| B.AI x402 协议 | 结算时的自主微支付 | 交易记录显示在结算流程中 | AI/Web3 融合 |
| TRON Shasta 测试网 | 完整合约部署与执行 | 钱包 + 交易历史 | 产品完成度 |
| $HTX 代币经济 | 费率折扣与回购展示 | 交易面板 + KPI 卡片 | 商业与生态潜力 |

> **核心叙事**："我们不只是拼接 API。RESOLVE 是建立在 HTX 生态之上的——Agent 通过 8004 协议上链、通过 x402 自主支付、使用 HTX 行情数据推理。产品的每一层都在消耗一项生态资源。"
