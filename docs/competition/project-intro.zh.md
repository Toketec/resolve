## 解决的问题

当前预测市场依赖两种有缺陷的裁决机制：

1. **中心化预言机**（如 Polymarket 的 UMA）— 人类持币投票裁决，需要**数天**时间，容易被操纵，无法处理复杂结果
2. **单点 AI 预言机** — 单一模型的判断，无交叉验证、无证据透明、无降级方案

两种方式都造成了信任瓶颈，限制了预测市场只能处理简单的二元结果，阻碍了主流用户采用。

---

## 解决方案

**RESOLVE 用多 AI 智能体共识取代人类仲裁。** 市场到期时，6 个独立 AI 智能体——每个专注于一个不同的分析维度（交易所数据、技术基本面、新闻情绪、监管政策、链上数据、宏观经济学）——并行收集证据并投票。加权共识算法汇总裁决结果，最终通过 TRON 测试网链上结算。

**核心流程：** 连接钱包 → 买入 YES/NO → 市场到期 → 6 Agent 并行推理（~5秒）→ 达成共识 → 链上结算

## 核心亮点

### 1. 6 Agent 并行共识（不是 ChatGPT 包装）

- 6 个专业 Agent（交易所、技术、媒体、监管、链上、宏观）通过真实 LLM 独立推理
- 加权 6 票共识**约 5 秒**完成裁决 — UMA 人类投票需要数天
- 每票关联可验证证据（价格数据、新闻来源、链上数据）

### 2. AI 原生，不是加密包装

- Agent 是**仲裁者**而非交易顾问——替代的是 UMA 的人类投票者，而非告诉用户该押哪边
- 全自动裁决流水线：证据收集 → LLM 推理 → 共识 → 链上结算

### 3. TRON 生态原生集成

- 通过 **USDD TRC-20** 在 TRON Shasta 测试网结算
- Agent 身份通过 **B.AI 8004 协议**注册
- 自主 Agent 微支付通过 **B.AI x402 协议**触发
- $HTX 代币经济：费率折扣与回购展示
