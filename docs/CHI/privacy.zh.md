# ⟁ RESOLVE：隐私政策

## 我们收集什么数据，如何使用

> **版本**: 1.0 · **日期**: 2026 年 7 月  
> **适用范围**: 本政策适用于 RESOLVE 应用（`resolve-prediction.vercel.app`）

---

## 1. 我们收集什么

RESOLVE 是一个构建在 Web2 + Web3 混合架构上的预测市场平台。我们仅收集运营平台所必需的数据。

### 1.1 钱包地址

当你连接 TronLink 钱包使用 RESOLVE 时，我们会在 Supabase PostgreSQL 数据库中存储你的 **TRON 钱包地址**（例如 `TXYZ...`）。这用于：

- 在投资组合页面展示你的持仓和交易历史
- 记录你在市场结算中的参与
- 将链上交易链接到你的账户

**我们从不存储你的私钥。** 你的私钥始终只存在于你的 TronLink 钱包中。我们仅在你签名连接请求后接收公开的钱包地址。

### 1.2 预测市场活动

我们记录以下与你的钱包地址关联的活动：

- 你创建的市场（标题、描述、裁决条件、到期时间）
- 你持有的头寸（市场、方向、金额）——用于展示和结算
- AI 智能体裁决的共识投票和证据日志

这些数据存储在 Supabase PostgreSQL 中，通过 `wallet_address` 外键链接到你的钱包地址。

### 1.3 网站使用数据

我们使用 Vercel 内置的分析功能收集匿名使用数据：

- 页面浏览、来源、浏览器类型、设备类型
- 大致地理区域（仅国家级别）
- 会话时长和交互模式

这些数据是**汇总和匿名化**的——无法链接回你的钱包地址或个人身份。

### 1.4 区块链数据

当你与 RESOLVE 在 TRON Shasta 测试网上的智能合约交互时：

- 你的钱包地址和交易哈希在 TRON 区块链（Shasta 浏览器）上公开可见
- 结算交易数据永久记录在链上
- 通过 B.AI 8004 协议注册的 AI 智能体身份数据在链上公开可验证

**我们无法删除或修改链上数据**——区块链的不可篡改性是其核心特性。

## 2. 我们如何使用你的数据

| 数据 | 用途 | 法律基础 |
|:-----|:-----|:---------|
| 钱包地址 | 身份识别、持仓展示、结算 | 合同必要性（提供服务） |
| 市场活动 | 核心产品功能 | 合同必要性 |
| 使用分析 | 改善体验、修复错误 | 合法利益 |
| 链上数据 | 信任最小化结算 | 公链透明性 |

**我们不会：**
- 向第三方出售你的数据
- 将你的数据用于广告或画像分析
- 与无关第三方分享你的钱包地址
- 分析你的交易模式用于展示投资组合以外的任何目的

---

## 3. 第三方服务

RESOLVE 依赖以下第三方服务：

| 服务 | 角色 | 共享的数据 | 隐私政策 |
|:-----|:-----|:-----------|:---------|
| **Supabase** | 数据库与认证 | 钱包地址、市场活动 | [supabase.com/privacy](https://supabase.com/privacy) |
| **Vercel** | 托管与分析 | 匿名使用数据 | [vercel.com/privacy](https://vercel.com/privacy) |
| **TRON** (Shasta 测试网) | 区块链结算 | 公开钱包地址、交易哈希 | [tron.network/privacy](https://tron.network/privacy) |
| **B.AI** | 智能体算力与身份 | 智能体推理提示（不含用户 PII） | [b.ai/privacy](https://b.ai/privacy) |
| **Claude (Anthropic)** | AI 智能体推理 | 市场证据文本（不含用户 PII） | [anthropic.com/privacy](https://anthropic.com/privacy) |

AI 智能体的推理调用仅使用**市场裁决条件和公开数据**——你的钱包地址、个人信息和交易历史不会被发送给 LLM 提供商。

## 4. 数据保留

| 数据类型 | 保留期限 | 依据 |
|:---------|:--------:|:-----|
| 市场元数据与头寸 | 无限期（平台运营期间） | 核心产品状态 |
| 钱包→头寸关联 | 无限期 | 投资组合展示与结算审计 |
| 链上结算数据 | 永久（不可变账本） | 区块链特性 |
| 匿名使用分析 | 滚动 12 个月 | 产品改进 |
| 服务器日志 | 30 天 | 调试与安全 |

你可以随时联系团队请求删除链下数据。链上数据无法删除。

## 5. 你的权利

你有权：

1. **访问**：请求获取与你的钱包地址关联的所有数据副本
2. **更正**：纠正我们持有的任何不准确数据
3. **删除**：请求删除你的链下数据（我们将匿名化或移除 Supabase 记录）
4. **可移植性**：导出你的持仓和市场历史
5. **反对**：反对我们出于任何目的处理你的数据

如需行使这些权利，请通过第 7 节中的联系方式联系我们。

**重要限制**：记录在 TRON 区块链上的数据（结算交易、8004 注册）无法修改或删除——这是我们依赖信任最小化结算的区块链架构所固有的。

---

## 6. 安全措施

我们实施以下安全措施：

- **不存储私钥**——钱包交互完全通过 TronLink 在客户端进行
- **LLM 提示中不含 PII**——AI 智能体仅接收市场数据，从不接收用户信息
- **API 路由验证签名**——每个服务器操作都需要有效的钱包签名
- **Supabase 行级安全**——用户只能访问自己的头寸数据
- **Vercel 部署**——强制 HTTPS，包含 DDoS 防护
- **定期依赖审计**——每次部署时运行 pnpm audit

尽管如此，RESOLVE 是一个**正在积极开发的黑客松项目**。我们建议：

- 仅使用测试网代币（Shasta TRX）
- 不要存入真实资产
- 将平台视为实验性产品
