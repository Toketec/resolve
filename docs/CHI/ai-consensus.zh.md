# ⟁ RESOLVE：AI 共识机制

## 六个智能体，一个最终裁决 — AI 陪审团如何达成一致

> **版本**: 1.0 · **协议**: 加权多智能体共识 · **共识阈值**: 0.65
> **目标**: 用 5 秒 AI 审议取代 UMA 长达数天的人工投票

---

## 为什么要「AI 共识」？

预测市场的核心只有一个问题：**市场到期后，结果是什么？**

"2026年12月31日之前比特币能否突破15万美元？"——市场到期了，谁来裁定结果是 YES 还是 NO？

传统方案（Polymarket 的 UMA 机制）靠的是**持币人人工投票**。一群人在 Discord 里讨论两天，然后手动投出结果。过程不透明、周期长、容易扯皮。灰色问题（"这算突破还是没突破？"）尤其棘手。

RESOLVE 的做法完全不同：我们派出 **6 个 AI 智能体**，每个专注一个分析领域。它们同时收集证据、独立投票、加权汇总——**整个过程大约 5 秒**。

---

## 加权投票系统

不是所有智能体都应该有同样的发言权。一个历史准确率 97.2% 的交易所专家，当然比一个泛泛分析者更有分量。每个智能体都有一个**权重**——基于其角色、专长和历史表现确定的固定乘数。

| 智能体 | 呼号 | 立场 | 权重 | 为什么是这个权重 |
|--------|------|:----:|:----:|----------------|
| 交易所预言机 | BULL-1 | 看多 | **1.0** | 准确率最高（0.972）。直接接入 HTX 实时价格数据——信息密度最大的信号源 |
| 技术预言机 | BULL-2 | 看多 | **0.8** | TEE/L2 基本面分析——补充视角，但不如价格数据直接 |
| 媒体预言机 | BEAR-1 | 看空 | **0.8** | 新闻情绪和监管风险——有价值的制衡，但天然噪音大 |
| 监管预言机 | BEAR-2 | 看空 | **0.8** | 全球监管政策——结构上重要，但变化缓慢 |
| 链上预言机 | NEUT-1 | 中立 | **0.9** | 链上数据与巨鲸追踪。数据驱动，偏差小 |
| 宏观预言机 | NEUT-2 | 中立 | **0.9** | 宏观经济与地缘政治。长线数据导向 |

**权重设计逻辑：**

- **BULL-1 权重 1.0**：因为它看到的证据（HTX 实时盘口+价格走势）是对问题最直接的输入。它已裁决 4,181 个市场，准确率 97.2%——所有智能体中最高的。
- **NEUT 权重 0.9**：纯数据驱动的分析几乎没有立场偏差。它们的准确率（0.964 和 0.929）反映了严谨的证据推演。
- **BULL-2、BEAR-1、BEAR-2 权重 0.8**：重要但都是次级信号——技术面、情绪、监管——支持但不决定价格走势。

v1 中权重**不动态调整**，在注册时根据角色设定并通过智能体生命周期维护。未来版本可能会引入基于历史准确率的动态权重。

## 共识流水线

一个市场从到期到结算的完整流程：

```
市场到期触发
         │
         ▼
┌─────────────────────────────────┐
│  第一步：并行证据收集（6 路）      │
│  ├─ BULL-1 → HTX 价格/盘口数据    │
│  ├─ BULL-2 → TEE 部署数据        │
│  ├─ BEAR-1 → 新闻流、社交情绪      │
│  ├─ BEAR-2 → 全球监管数据库       │
│  ├─ NEUT-1 → 链上巨鲸追踪         │
│  └─ NEUT-2 → 宏观经济指标         │
│  每路 300–800ms                  │
└──────────┬──────────────────────┘
           ▼
┌─────────────────────────────────┐
│  第二步：各智能体独立投票（6 路 LLM）│
│  每个返回：                       │
│  { vote: YES/NO,                │
│    confidence: 0.0–1.0,        │
│    evidence: 引用[],            │
│    reasoning: 推理过程 }          │
│  总耗时 ~5秒（Promise.all 并行）   │
└──────────┬──────────────────────┘
           ▼
┌─────────────────────────────────┐
│  第三步：加权共识计算              │
│                                  │
│  yesWeight = Σ(权重 × 置信度)     │
│               所有 YES 票         │
│  noWeight  = Σ(权重 × 置信度)     │
│               所有 NO 票          │
│                                  │
│  结果 = yesWeight ≥ noWeight ?   │
│         YES : NO                 │
│  共识强度 = 大值 / (大值+小值)     │
└──────────┬──────────────────────┘
           ▼
┌─────────────────────────────────┐
│  第四步：阈值检查                  │
│                                  │
│  共识强度 ≥ 0.65 ?               │
│    → ✅ 共识达成，裁决生效          │
│    → ⚠️ 低于阈值，进入争议模式     │
│         （详见"争议模式"文档）      │
└─────────────────────────────────┘
```

### 为什么是 0.65？

这个阈值是在两个极端之间找平衡：

- **太低（比如 0.51）**：微弱多数就触发结算。三个智能体勉强选 YES，三个勉强选 NO，51% 的共识根本不能反映真实不确定性。
- **太高（比如 0.85）**：争议太罕见。即使证据充分，也总会有智能体给出异常票（比如看空智能体注意到了多头忽略的负面新闻）。执行不了的阈值同样损害信任。

**0.65** 是甜区：它要求一个清晰的超级多数才宣布共识，同时不让门槛高到无法实现。实践中，0.65 意味着至少需要**两个高置信度的 YES 票**才能压倒反对票——这是一个有意义的差距，让参与者相信系统在真实运作。

如果共识强度低于 0.65，系统进入**争议模式**，而不是强行宣布一个不确定的裁决（详见[争议模式](./dispute-mode.zh.md)）。

## 证据透明：每个投票都有引用

这不是一个黑箱预言机。每个智能体的投票都附有**可验证的引用链接**——你可以点击查看它基于什么数据做出的判断。

```json
{
  "agent": "BULL-1 (交易所预言机)",
  "vote": "YES",
  "confidence": 0.89,
  "evidence": [
    {
      "source": "HTX API: 行情详情",
      "url": "https://api.htx.com/market/detail/merged?symbol=btcusdd",
      "snippet": "当前价格: $168,430。7日涨幅 8.2%。"
    },
    {
      "source": "HTX API: 盘口深度",
      "url": "https://api.htx.com/market/depth?symbol=btcusdd&type=step0",
      "snippet": "买卖价差 0.03%。$165k 附近有强买单支撑。"
    }
  ]
}
```

每个智能体的 `evidence` 数组在 UI 中展示，附带完整的源 URL。参与者可以点击查看原始数据源。这就形成了一个**完整的审计链**——每一次裁决都可以追查到产生它的原始证据。证据数据存储在 Supabase（Web2 数据库）中以实现快速查询，只有最终的结算结果通过 `settleBatch()` 记录在链上——需要不可篡改的只有资金转移。

## 速度对比：5 秒 vs 2–3 天

RESOLVE 和 UMA 预测市场最直观的差异：

| 指标 | UMA（人工投票） | RESOLVE（AI 共识） |
|------|:--------------:|:-----------------:|
| 裁决耗时 | **2–3 天** | **~5 秒** |
| 投票成本 | 高（Gas + UMA 质押） | 几乎为零（B.AI x402 微支付） |
| 透明度 | 不透明（Discord 讨论） | 完全透明（每票附引用） |
| 可用性 | 仅限投票窗口期 | 随时可用（6 个智能体昼夜在线） |
| 错误率 | 复杂市场约 5–8% | 约 3–5%（持续改善） |

对于几分钟内就出结果的市场（比如"比特币会在一小时内跌破 6 万美元吗？"），UMA 的两天周期根本不可行。AI 共识让**实时裁决**成为可能。

## 信任模型：没有单点故障

RESOLVE 的信任模型不依赖于任何一个智能体的绝对正确，而在于**多视角的多样性**。

1. **六个独立视角**：一个看多的价格分析师、一个看空的消息读者、一个中立的链上观察者——它们几乎不可能同时犯同样的错误。不同的分析透镜形成了天然的纠错机制。

2. **按历史表现加权**：准确率高的智能体有更大发言权——不是因为它们在任何单个问题上"正确"，而是因为它们的长期判断与更好的结果正相关。

3. **证据完全透明**：每个投票都引用来源。任何人可以质疑数据、推理或裁决——争议机制（见[争议模式](./dispute-mode.zh.md)）为这种质疑提供了经济激励。

4. **智能体链上身份**：每个智能体通过 B.AI 8004 协议在 TRON 上注册。它们的身份、权重和性能数据公开可查（见[智能体注册表](./agent-registry.zh.md)）。

> **一句话总结**：RESOLVE 不要求你相信任何一个 AI。它要求你相信一个系统——3 个立场 × 2 个智能体相互校验，形成一个你可以检查、质疑和验证的裁决，整个过程不到 10 秒。
