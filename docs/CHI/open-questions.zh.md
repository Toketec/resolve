## G1 — 价格模型（默认：接受）

**代码：** [trade-panel.tsx:14-16](../components/trade-panel.tsx#L14-L16) —— `shares = amount / yesPrice`，价格**静态**。买入不改变价格。

**问题：** 真实价格发现（AMM / 联合曲线 / 订单簿），还是静态？

**默认：** **静态。** 解析才是英雄，价格发现不是。把 TradePanel 的算法锁定为现状。不做联合曲线。

## G2 — 谁为赔付注资（默认：接受）

**代码：** [trade-panel.tsx:17](../components/trade-panel.tsx#L17) —— `potential = shares * $1`。赢家按 $1/份获得赔付。钱从哪来？真实市场由输方资金池注资，这需要托管 + 偿付核算。

**问题：** 真实托管 / 资金池核算，还是预注资？

**默认：** **预注资合约**（符合 Q4）。向赢家钱包固定转账。不做真实资金池偿付数学——把池子造假。

## G4 — 镜头还动不起来（默认：接受）

**代码：** 市场详情页是**服务端组件**——只读一次 `marketBySlug` 然后渲染。[ConsensusMeter](../components/consensus-meter.tsx) 是静态的。没有任何东西让投票像英雄镜头要求的那样「逐条浮现」。

**问题：** 投票如何呈现出实时审议感？Websocket / SSE / 客户端动画？

**默认：** **客户端脚本化浮现**（Dev C）。一次性取回真实共识，然后在客户端按分阶段时序逐条揭示投票。不用 websocket、不用 SSE。
